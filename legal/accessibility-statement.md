# Accessibility Statement

**BackOffice Pro (Pty) Ltd**
**Survey Verification Platform**

---

**Effective Date:** 1 January 2025
**Version:** 1.0

---

## 1. COMMITMENT

1.1 BackOffice Pro (Pty) Ltd ("BackOffice Pro") is committed to ensuring that the Survey Verification Platform is accessible to all users, including those with disabilities.

1.2 We strive to conform to the Web Content Accessibility Guidelines (WCAG) 2.2 Level AA.

1.3 Accessibility is integrated into our design and development processes.

---

## 2. ACCESSIBILITY STANDARDS

2.1 The Platform aims to meet:
   - WCAG 2.2 Level AA
   - Section 508 of the Rehabilitation Act
   - EN 301 549 (European accessibility standard)
   - The South African Web Content Accessibility Guidelines

2.2 We are working towards WCAG 2.2 Level AAA compliance for key user flows.

---

## 3. CURRENT STATUS

3.1 The Platform is substantially conformant with WCAG 2.2 Level AA. Known issues are tracked and addressed in our development backlog.

3.2 Accessibility features include:
   - Semantic HTML structure
   - Keyboard navigation for all interactive elements
   - Screen reader compatible content (ARIA labels and roles)
   - Color contrast ratios meeting AA standards (minimum 4.5:1 for text)
   - Responsive design for various viewport sizes and zoom levels
   - Focus indicators for keyboard navigation
   - Alt text for meaningful images
   - Captions and transcripts for multimedia content
   - Form labels and error messages accessible to assistive technology
   - Skip navigation links
   - Consistent navigation patterns

---

## 4. KNOWN LIMITATIONS

4.1 We are aware of the following accessibility limitations:
   - Some complex data visualizations may not be fully accessible
   - Third-party embedded content may not meet all accessibility standards
   - Some interactive map features may have limited keyboard access

4.2 We are actively working to address these limitations.

---

## 5. TESTING AND EVALUATION

5.1 The Platform is tested using:
   - Automated testing tools (axe-core, Lighthouse)
   - Manual testing with screen readers (NVDA, VoiceOver, JAWS)
   - Keyboard-only navigation testing
   - Color contrast analysis
   - User testing with people with disabilities

5.2 Accessibility audits are conducted quarterly.

---

## 6. ALTERNATIVE FORMATS

6.1 Content from the Platform is available in alternative formats upon request:
   - Large print
   - Plain text
   - Audio
   - Screen reader compatible documents

6.2 Requests can be made to accessibility@backofficepro.com.

---

## 7. ASSISTIVE TECHNOLOGY COMPATIBILITY

7.1 The Platform is designed to work with:
   - Screen readers (JAWS, NVDA, VoiceOver, TalkBack)
   - Screen magnifiers
   - Voice recognition software
   - Keyboard-only navigation
   - Switch access devices
